## 🎯 How URL Tracking Works

### Discovery Phase
```python
# In web_search() or execute_query()
search_results = web_search(query)
urls = [r.url for r in search_results]
url_tracker.register_urls(urls, discovered_by="web_condenser")
```

### Processing Phase
```python
# After reading page content
page_text = await read_page(url)
quality_metrics = calculate_data_quality(page_text)
url_tracker.update_url_quality(
    url,
    has_community_data=quality_metrics["has_community_data"],
    data_quality_score=quality_metrics["data_quality_score"],
    data_types_found=quality_metrics["data_types_found"],
    data_summary=quality_metrics["data_summary"],
    status="printed"
)
```

### Failure Tracking
```python
# If page can't be read
url_tracker.update_url_status(
    url,
    status="failed",
    error_message="Page could not be read",
    http_status=400
)
```

## 📊 Data Quality Metrics

The `calculate_data_quality()` function analyzes page content for:
- **Fees keywords**: HOA, dues, assessment, monthly fee, etc.
- **Amenities keywords**: pool, tennis, golf, clubhouse, etc.
- **Demographics keywords**: population, median age, income, etc.
- **Proximity keywords**: shopping, hospital, school, library, etc.

Score calculation:
- 10 points per keyword match (max 25 per category)
- Length bonus: 1 point per 200 chars (max 25)
- Final score: 0-100
